# 动态上下文与意图开关：macOS 回归检查

在 Windows 上新增了「动态上下文」（仅 Windows），并把「自动识别意图」改成默认关闭的开关。`active_app_context/mod.rs` 的 `DictationContextCaptureHandle` 改成了结构体，非 Windows 的分支只在 Windows 上做过类型推演，没有真机编译。

- [ ] `npm run tauri:dev` 能编译通过：`active_app_context/mod.rs` 里 `#[cfg(not(windows))]` 的分支（`begin_dictation_capture`、`resolve_dictation_capture`、`cancellation`）没有未使用变量之外的错误。
- [ ] 智能处理 →「当前软件上下文」里不显示「动态上下文」开关。
- [ ] 智能模型选本地听写整理模型时出现「自动识别意图」，默认关闭：关闭时选中文字再听写，结果照常按听写插入，不弹回答窗。
- [ ] 打开「自动识别意图」后，选中文字说「翻译成英文」会按意图分发，与改动前一致。
- [ ] 助手「选区编辑」的智能模型下拉里有本地听写整理模型；选它后选中文字说修改要求，结果替换选区。
