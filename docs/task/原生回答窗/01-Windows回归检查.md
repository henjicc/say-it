# 原生回答窗：Windows 真机检查

原生回答窗默认开启，`SAYIT_NATIVE_ASSISTANT=0` 回退到 WebView 回答窗。外观可先在「开发者 → 原生窗口测试 → 智能助手回答窗」里看各状态；下面这些要用真实听写和真实回答确认。

## 出现与关闭

- [ ] 在网页里选中一段英文说「翻译成中文」：回答窗左上角对齐此刻的鼠标位置；鼠标靠近屏幕右边或底部时只挪开刚好放得下的距离。
- [ ] 问答、以及网页上不可编辑选区的改写：说完立刻弹出回答窗显示「正在生成回答…」，随后文字逐步出现，不是等全部生成完才显示。
- [ ] 回答窗出现后立刻有键盘焦点：直接打字进入输入框（问答类回答），按 Esc 关闭。
- [ ] 没置顶时点别的窗口，回答窗关闭；点图钉置顶后点别处不关闭，图钉变成强调色。
- [ ] 拖动顶部空白处能移动窗口；回答变长时窗口向下长高，碰到屏幕底部时整体上移，超过上限后正文出现滚动条。
- [ ] 高分屏（150%、175%）与跨屏拖动后，文字清晰、没有错位。

## 正文

- [ ] 流式回答逐步出现，滚动条贴着底部跟随；手动往上滚之后不再被拉回底部。
- [ ] 标题、列表（含嵌套与任务列表）、引用、代码块、表格、行内代码、加粗、链接都正确显示；翻译结果照原文分行。
- [ ] 鼠标拖选正文、双击选词、三击选段，Ctrl+C 复制的文字与所选一致；拖到窗口外时正文跟着滚动。
- [ ] 点链接用浏览器打开；拖选时经过链接不会打开。
- [ ] 点「复制」后图标变成对勾，剪贴板是完整回答（Markdown 原文）；「重新生成」「插入」按原逻辑工作。
- [ ] 「思考过程」可展开收起；多轮追问时「前 N 轮」可展开看之前的问答。

## 输入与追问

- [ ] 中文输入法（微软拼音、搜狗）在输入框里组字：组字串带下划线显示在光标处，候选窗贴在光标下方、不挡住正在输入的那行。
- [ ] Shift+回车换行，回车发送；生成中不能发送，草稿保留。发送失败时草稿放回输入框。
- [ ] Ctrl+A/C/X/V 在输入框内可用；左右、上下、Home、End、Backspace、Delete 行为正常，emoji 不会被删掉一半。
- [ ] 点麦克风开始语音追问：输入区换成语音条，波形随说话起伏，实时显示识别文字；点语音条结束并发送，Esc 放弃。
- [ ] 回答窗有焦点时按住听写快捷键：开始语音追问，提示「松开 … 发送」，松开后发送；点别的软件再按快捷键是普通听写（置顶时同样如此）。
- [ ] 翻译、改写这类没有对话上下文的回答不显示输入框，快捷键仍是普通听写。
