# 原生悬浮球设置面板：macOS 真机检查

macOS 后端只在 Windows 上做过类型检查，先跑一遍 [01-Windows回归检查](01-Windows回归检查.md) 的条目，再看这些 Mac 特有的项。

- [ ] 右键（或 Control+点按）悬浮球弹出面板，说吧本身没有被激活（菜单栏仍是原来的应用），面板能收到 Esc、Tab 和方向键。
- [ ] 点别的应用后面板收起。
- [ ] 触控板左右滑动不会误调滑块；上下滑动在滑块上调值速度自然。
- [ ] Retina 屏与外接非 Retina 屏上面板贴着悬浮球，不跑到别的屏。
- [ ] 开了毛玻璃时面板背后的材质圆角与面板一致。
