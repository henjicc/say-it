# 原生悬浮球设置面板：Windows 真机检查

原生悬浮球（默认）右键弹原生设置面板；`SAYIT_NATIVE_ORB=0` 时悬浮球和面板一起回退 WebView。外观可先在「开发者 → 原生窗口测试 → 悬浮球设置面板」里看；下面这些要在真实悬浮球上确认。

- [ ] 右键悬浮球：面板贴在球右侧、与球纵向居中；球靠近屏幕右边时改到左侧，靠近上下边时不超出工作区。
- [ ] 面板出现后立刻有键盘焦点：按 Esc 收起；点桌面或其它窗口收起；点右上角关闭收起。
- [ ] 拖「大小」滑块：悬浮球跟着实时变大变小，不卡顿、不跳回；松手后数值停在松手处。拖出面板左右两端停在最小、最大值。
- [ ] 拖「不透明度」滑块：悬浮球透明度实时变化。鼠标停在滑块上滚轮一格改 1。
- [ ] 「自动回车」开关点一下立即切换，主窗口里的同一设置同步变化；在主窗口改，面板开着时也同步。
- [ ] 「恢复大小与不透明度」把两项恢复到 3.0% 和 100%，滑块与悬浮球都跟着变。
- [ ] 「打开软件主界面」收起面板并打开主窗口。
- [ ] 「关闭悬浮球」收起面板和悬浮球；悬浮球语音输入进行中点它时，面板底部显示红色原因，面板变高但不超出屏幕。
- [ ] 键盘：Tab / Shift+Tab 在关闭按钮、两条滑块、开关和三个操作间移动并显示蓝色焦点框；方向键调 1、PageUp/PageDown 调 10、Home/End 到两端；空格或回车触发开关和按钮。
- [ ] 高分屏（150%、175%）与副屏上：文字清晰，面板位置正确，拖滑块数值与指针位置对得上。
- [ ] 任务管理器里右键悬浮球后不再出现新的 msedgewebview2 进程。
