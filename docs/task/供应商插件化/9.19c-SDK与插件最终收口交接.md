## 真实验收边界

9.18 经过正式 `System CredentialStore → BuiltinSdkRuntime → Rust Host API → QuickJS → SDK 0.2.2` 链路，但所有代表项都在供应商网络前终止：

- 百炼 `provider:bailian:apiKey` 不存在；短音频、文件异步、Fun realtime、Qwen realtime、Qwen-MT Flash/Plus/Lite 均为 `missing_credential`，HTTP/WS/上传/轮询为 0。
- Groq 目标 Keychain 项元数据存在，但 macOS 读取没有返回；修复后最后一次在约 10 秒宿主 deadline 受控返回 `timeout`，未进入模型发现或聊天网络。
- 预取消场景通过；所有场景的 HTTP stream、WS、span/timer 资源均归零，脱敏 recorder 未发现 Authorization/key/Base64 载荷泄漏。
- 实际可计费请求：**0**；没有 transcript、译文、reasoning、text、usage、finish 或远端 task ID 成功证据。

因此，自动化和宿主协议收口已经完成，但真实百炼与 Groq 成功响应仍是外部环境前置，而不是本轮已完成事项。
