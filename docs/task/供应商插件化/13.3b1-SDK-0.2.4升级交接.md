- lock 指向 GitHub Packages 已发布包：

  - integrity：`sha512-k/k7bFj2b0vXc4nDd7VIHJblpp67gD8mivXY9K+Lu5u21BhqSs51vnDfQgG79tQe1qOhboVjrdVDZl1Yak56Gg==`

## 按需隔离处理

SDK 0.2.4 的通用 LLM chat/discovery 内核会经 `endpointProfiles` 静态带入 BigModel profile。Say-It 的 Groq bundle 在构建期将这一层替换为仅接受 Groq、且不注册 endpoint profile 的身份解析边界；Groq 的 SSE、模型发现、取消、凭据和宿主 transport 仍使用 SDK 内核，没有复制执行器。

构建脚本把 `/dist/llm/bigmodel/` 加入 Groq 与外部 LLM module 的禁止输入列表，发现越界会直接失败。百炼 capability bundle 原有的 `/dist/llm/` 禁止规则保持不变，generation/catalog 也继续禁止。

## 后续边界

- 若 Say-It 将来选择接入 BigModel，应显式增加产品入口，并按 `providerFamilyId=bigmodel`、`endpointProfile=cn|global`、区域独立 `credentialId` 接入；不得复用本任务的 Groq-only 边界。
- SDK 后续若提供不静态注册任何 endpoint family 的通用 LLM core 子入口，可删除 Say-It 的 Groq endpoint identity 构建替换，直接消费该按需入口。
- 工作区中同时存在其他任务的 Rust/UI 未提交改动，本任务提交只包含上述精确文件/区块。
