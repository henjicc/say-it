## 发现并修复的问题

静态复核发现并修复两类问题：

- `8803d41 docs(plugins): 更正 v5 唯一协议规则`
- `fa97079 fix(sdk-runtime): 隔离 Groq 文本运行时依赖`
- `19b2b94 docs(plugins): 统一模型包 v5 规则`

第一项把 JavaScript 插件规则改为 v5，但首次仍沿用了旧的“v4 model-pack”描述；第二轮独立审计以实际构建器和官方 manifest 为准纠正为 v5，并同步操作手册。现有 `rejects_v3_and_v4_without_compatibility_branches`、Skill validator、v5 fixture 与 model-pack 宿主测试构成回归证据。

Groq 问题的根因是 SDK 0.2.2 通用 chat 入口把不相关 APIMart/Fal/KIE/PPIO 上传预处理静态带入 Groq bundle，其中包含 `generation` credential scope。最终修复没有复制 SSE/LLM 内核：只在 Say-It 的文本产品边界替换媒体预处理，构建脚本对 `/dist/upload/` 等路径硬拒绝，bundle 测试同时断言模块数与多媒体拒绝。修复前 363,759 bytes / 118 modules，修复后 349,532 bytes / 99 modules。
