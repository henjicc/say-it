正式入口：


## source 与正式模块 ID

- source namespace 固定为 `@henjicc/ai-sdk`，descriptor 必须是 `{ kind: "builtin", namespace: "@henjicc/ai-sdk" }`。
- module source 只接受：`bailian-speech-recognition`、`bailian-speech-recognition-realtime`、`bailian-translation`、`groq-llm`。
- 百炼 capability 共 12 个：5 个非实时 ASR、4 个实时 ASR、3 个翻译。
- 正式 ASR module ID 使用 `bailian.speech-recognition.*`；模型名中保留 `fun-asr` 只表示百炼模型/协议族，不是 provider alias。
- 翻译 ID：`bailian.translation.qwen-mt-flash`、`bailian.translation.qwen-mt-plus`、`bailian.translation.qwen-mt-lite`。
- Groq provider ID 为 `groq`，默认模型为 `openai/gpt-oss-20b`。

## 9.13b 直接输入

1. 使用 `__sayitCreateSdkRuntime({ sources, capabilityOptions })` 创建 provider-scoped handle；只注册该业务路由需要的 source，完成后调用 `dispose()`。
2. 百炼绑定沿用 9.16：SDK `provider_id=bailian`，凭据键 `provider:bailian:apiKey`，scope 为 `speech-recognition` 或 `translation`。
3. Groq 绑定沿用 9.16：SDK provider ID 是 `groq`，Say-It profile ID/凭据身份是 `llm-groq`；绑定 `CredentialKey::provider("llm-groq", "apiKey")`，不要增加 alias 分支。
4. 非实时 ASR 输入媒体优先传宿主 media ref，由 `RuntimeContext.media.read` 读取；实时音频持续通过宿主 WebSocket bridge 发送。
5. 切路由时直接使用新的 `bailian.*` module ID；不要做 `funasr -> bailian` 兼容，旧状态已经由 9.16 一次迁移。
6. 迁移一个路由、验收一个路由；在 SDK 路由全部稳定前保留旧 Rust 实现。9.13a 本身没有删除或改变现有执行路径。
