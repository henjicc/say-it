# 10.1 本地加密凭据库交接

## 结论

Say-It 的生产凭据存储已从系统 Keychain / Credential Manager / `keyring` 迁为应用自管的本地加密 vault。运行时不再调用系统凭据 API，因此不会再因读写供应商密钥触发系统密码或授权弹框。

`CredentialStore` 领域接口保持 `get/set/delete` 不变；Rust 宿主仍只按 `provider + scope` 或插件命名空间向 QuickJS 注入短生命周期值，WebView 没有读取凭据的 API。

## 存储位置与格式

- vault 固定在应用默认私有数据目录的 `credentials/` 子目录，不随用户自定义数据目录迁移。
- macOS：`~/Library/Application Support/com.henjicc.sayit/credentials/`
- Windows：当前用户的本地应用数据目录下 `com.henjicc.sayit/credentials/`
- `master.key`：首次写入前由系统随机源生成的 32 字节主密钥，与密文分文件保存。
- `vault.json`：仅保存 `version`、`algorithm`、随机 `nonce`、`ciphertext`；provider、scope、插件 ID、账号索引和 secret 均位于密文内。
- 算法：AES-256-GCM；每次写入使用随机 96-bit nonce，并绑定固定版本 AAD。
- 原子性：临时文件落盘后替换主文件，更新前保留可验证备份；主文件损坏时只接受能通过 AEAD 校验的备份。
- 并发：进程内统一互斥锁包围完整读改写事务；Say-It 的单实例约束避免多进程同时写入。
- Unix：目录权限 `0700`，主密钥、vault、备份和临时文件权限 `0600`。
- Windows：位于当前用户私有 Local App Data，并继承其 ACL；本任务不调用 Credential Manager 或 DPAPI。

主密钥没有硬编码、没有从常量或机器 ID 派生，也没有写进 `vault.json`。

## 安全边界

该方案用于避免配置文件明文窥视、备份误传和普通日志泄漏，并能检测密文篡改或错误主密钥。主密钥和密文虽然分文件保存，但均受同一操作系统用户权限保护，因此**不能抵抗已经控制当前用户账户、能够读取应用私有目录或注入 Say-It 进程的攻击者**。这不是硬件密钥或系统钥匙链的等价威胁模型。

日志与错误只报告 provider/scope、状态和脱敏错误，不记录 secret、Authorization、密文或主密钥。

## schema v4 与一次性迁移

- 持久化 schema 已从 v3 升到 v4。
- v2 及仍存在明文 `api_key` 的旧配置：先写入并回读校验 local vault；全部成功后才从主配置和备份删除明文并写入 v4。任一写入失败时保留原配置与明文，允许下次启动重试，不会丢密钥。
- v3 且配置中已无明文：不读取旧 Keychain，不猜测旧值，直接升级到 v4。对应供应商在设置页显示“需要填写”。
- 旧 Keychain / Credential Manager 条目不再读取、迁移或删除；用户需要在设置页重新输入。
- 历史插件 `session.dpapi` 文件不会在启动或读取路径被打开；显式清除/卸载插件数据时可以删除该废弃文件，但不会调用系统凭据服务。

## 隔离与生命周期

- 内置供应商：`provider:<providerId>:<scope>`。
- 插件供应商密钥：`plugin:<pluginId>:provider:<providerId>:<scope>`。
- 插件浏览器会话：`plugin-session:<pluginId>:browserSession`。
- 插件卸载默认保留凭据，重新安装同 namespace 可继续使用；清除会话不会删除插件供应商 API key。
- QuickJS 沿用受控 blocking worker、宿主 deadline 和取消/资源释放路径；同步 JS 调用不会直接阻塞在文件 IO 上。

## 系统凭据方案删除清单

- 删除 `keyring` Cargo 依赖及其传递依赖。
- 删除 `SystemCredentialStore`、Keychain/Credential Manager 生产分支和平台凭据测试。
- 删除插件会话的 Keychain 分块与 Windows DPAPI 解密路径。
- live harness 改为向测试进程传入非敏感的 local vault 目录，不再假设 Keychain 可读。
- 设置、引导页、插件卸载提示和相关任务文档统一为“本地加密保存，不调用系统钥匙链”。
