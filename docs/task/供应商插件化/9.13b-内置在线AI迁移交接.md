# 9.13b 内置在线 AI 迁移交接

## 完成范围

- 百炼 9 个在线 ASR 模型统一走 `@henjicc/ai-sdk@0.2.1`：实时麦克风使用 SDK realtime session，短音频与文件识别使用 SDK capability execute。Rust 只保留录音、DSP、权限、宿主 HTTP/WS/media、取消和应用事件映射。
- Qwen-MT Flash、Plus、Lite 统一走 SDK translation capability，并把 SDK delta 继续映射到现有字幕翻译回调。
- Groq 对话、流式对话和模型发现统一走 SDK Groq 入口；默认模型仍为 `openai/gpt-oss-20b`。
- 百炼凭据从 `bailian/apiKey` 按 `speech-recognition` 或 `translation` scope 注入；Groq 从 `llm-groq/apiKey` 按 `llm` scope 注入。QuickJS 配置和业务输入均不带密钥。
- 内置 module ID 固定为 `bailian.speech-recognition.<model>`、`bailian.translation.<model>`；source 固定使用 SDK 0.2.1 的内置 source。
- Apple Speech、Sherpa/本地模型链路未修改。

## 删除与保留

已删除重复的 Rust 在线实现：

- 百炼实时 WebSocket 协议、connector 和旧 session 状态机。
- 百炼短音频请求、OSS 上传、异步任务提交/轮询/结果下载。
- 百炼 Qwen-MT HTTP/SSE 翻译实现。
- Groq 的 `genai` adapter 分支、Groq 专属 reasoning/body 映射和模型发现旁路。

仍保留：

- `genai` 通用执行层，继续服务 OpenAI、Anthropic、Gemini、DeepSeek、Kimi、智谱、MiniMax、自定义端点等非 Groq LLM。
- 百炼热词表管理 HTTP 实现。SDK 0.2.1 没有 vocabulary-management capability；它不是 ASR 执行旁路，但已改为从统一 CredentialStore 读取密钥。
- schema v3 的 `funasr -> bailian` 一次性数据/凭据迁移与历史记录迁移。运行时不再接受 `funasr` provider/kind。
- 模型注册表中的 `fun-asr-*` 是百炼官方模型 ID，不是旧 provider 兼容分支。

## 大媒体边界

- QuickJS 不再接收整段 JSON byte 数组：应用传入 opaque `media-ref`，宿主通过 `media.describe` 和 64 KiB `media.readChunk` 分块读取。
- SDK 0.2.1 的 MediaResolver 最终仍要求生成一个 `Uint8Array`，所以当前宿主在进入 QuickJS 前把单文件上限明确收紧为 10 MiB，超过时确定性拒绝；不会触碰 QuickJS 64 MiB 堆上限或发生不受控崩溃。
- 若后续要支持大于 10 MiB 的长音频，SDK 需要新增“宿主上传/流式 body media-ref”协议，让上传过程直接消费宿主分块，不能在 Say-It 再恢复供应商专属上传旁路。

## 已知 SDK 0.2.1 边界

- Groq SDK DTO 已覆盖 Say-It 当前默认模型、消息、max tokens、推理开关/effort、流式输出和模型发现。
- SDK 0.2.1 的 Groq DTO 尚未公开 temperature 与 JSON response format；Say-It 的 Groq 结构化场景目前仍依赖既有 system prompt 约束，未伪造未支持字段。后续应先扩 SDK 协议并发布新版本，再恢复对应精确控制。
- 百炼文件/异步识别使用 30 分钟能力超时；翻译、Groq 与建连使用 45 秒默认超时；实时收尾仍保留 8 秒应用超时。

## 真实验收入口

真实请求需用户授权并提供对应密钥；建议按以下最小集合验收：

1. 百炼：一个实时模型做麦克风开始/增量/结束；一个短音频模型；一个文件异步模型（文件不超过 10 MiB）。
2. Qwen-MT：Flash、Plus、Lite 各一条短文本，确认增量与最终译文一致。
3. Groq：默认 `openai/gpt-oss-20b` 做一次普通对话、一次流式对话、一次模型刷新。
4. 分别取消一次实时 ASR、文件 ASR 和 Groq 流式请求，确认 UI 状态收口且日志不含密钥、音频内容和完整提示词。
