# 悬浮球菜单修改必须广播完整设置并同步主窗口

右键菜单和主界面属于不同 WebView，各自持有独立内存状态。后端保存成功并隐藏悬浮球，不会自动更新主窗口的 Zustand 开关。

- 开关、自动回车和外观修改后通过同一配置事件广播完整快照，包括 `enabled`、`autoEnter`、外观与位置。主窗口只投影事件，不再发一次保存请求。
- 配置应广播一次，不循环调用多个 `window.emit`；后者仍是全局广播，会重复通知所有监听器。
- 后端返回前应释放配置锁再发事件。保存或窗口同步失败时沿用回滚路径，并重新投影恢复后的快照。
- 主窗口收到新快照后，不允许较早的外观保存响应把旧 `enabled` 覆盖回来。
- 回归验证菜单关闭后主界面立即显示关闭、重新打开正常、外观迟到响应不恢复旧开关。鼠标与窗口实际交互由用户实机验收。
