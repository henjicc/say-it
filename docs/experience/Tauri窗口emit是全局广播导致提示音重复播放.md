# Tauri 窗口 emit 是全局广播，提示音需定向派发

Tauri 2 的 `Emitter::emit` 即使调用于 `WebviewWindow`，仍向所有事件目标广播。悬浮球和常驻但隐藏的指示器都订阅 `dictation-indicator-play-cue` 时，两边都会播放一次，不能靠可见性判断是否会出声。

提示音必须通过 `app.emit_to(窗口标签, 事件, 载荷)` 发给唯一承载窗口。普通听写发给指示器、悬浮球听写发给悬浮球；指示器不存在时，明确回退到主窗口的提示音事件，不广播相同事件。波形这种单窗展示事件也应定向发送。

内置双音阶提示音本来就包含两个音符，不应为了排除重复派发而修改用户选择的音色。验收需分别测试常驻悬浮球和普通快捷键，确认一次启动只播放一组提示音。
