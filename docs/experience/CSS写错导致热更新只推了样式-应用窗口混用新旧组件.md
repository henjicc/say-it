# CSS 写错导致热更新只推了样式，应用窗口混用新旧组件

## 现象

改了一个组件（`.tsx`）和它导入的样式表（`.css`），浏览器单独打开看一切正常，但 `tauri:dev` 的应用窗口里布局错乱：元素跑位、旧文案还在、新动画不生效。

## 原因

改动过程中样式表曾有语法错误（如多了一个 `}`），Vite 报 `Internal server error: Missing opening {`。同一时刻推送的 `.tsx` 更新因为依赖这份坏掉的样式表而加载失败，窗口保留了旧组件。之后修好样式表，Vite 只推送了样式（日志里 `hmr update` 只有 `.css`），组件不会再被推送。结果窗口里是「旧组件 + 新样式」。

另开一个浏览器标签重新加载页面时拿到的是全新模块，所以看不出问题。

## 做法

- 热更新过程中出现过 Vite 报错，修好后要让应用窗口重新加载：重启 `tauri:dev`，或者再保存一次相关 `.tsx`，并在日志里确认 `hmr update` 包含该组件。
- 界面改动要在应用窗口本身核对，不能只在另开的浏览器标签里看。
- 排查时看 `tauri:dev` 日志里的 `hmr update` 和 `Internal server error` 行，能直接看出哪些模块没推送成功。
