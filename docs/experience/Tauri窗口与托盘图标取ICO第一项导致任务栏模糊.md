# Tauri 窗口与托盘图标取 ICO 第一项导致任务栏模糊

## 现象

Windows 任务栏和托盘里的图标明显发糊，但 `icon.ico` 里明明有 256 等高分辨率尺寸，Explorer 里看 exe 图标也正常。

## 根因

`tauri-codegen` 生成默认窗口图标时固定取 ICO 目录的第一项（`icon_dir.entries()[0]`），不是最大的一项。窗口的 `ICON_SMALL` 和托盘图标都用它。

ICO 按从小到大写时，第一项是 16px，150% 缩放下任务栏要画 36px，于是把 16px 放大。`npx tauri icon` 生成的 ICO 第一项是 32px，高缩放下同样会糊。

实拍对比（150% 缩放，任务栏绘制尺寸 36px，数值是与 36px 理想渲染的平均差异）：

| 窗口图标尺寸 | 差异 |
|---|---|
| 16 | 13.95 |
| 32 | 19.11 |
| 36 | 0 |
| 48 | 2.65 |
| 64 | 1.65 |
| 128 | 1.01 |
| 256 | 0.80 |

放大小图才糊，缩小大图很清晰，所以不需要按 DPI 写代码设置图标。

## 正确做法

1. `src-tauri/icons/icon.ico` 必须把最大尺寸排在第一项，其余尺寸的顺序不影响 Windows 选图。`scripts/app-icon.test.mjs` 守这一条。
2. 除常规尺寸外带上任务栏各缩放比例下的确切尺寸（24 × 缩放比：30、36、42、48、54、60、72、96）。固定到任务栏的快捷方式走 exe 资源，由 Windows 按尺寸选取。
3. 用 `npx tauri icon` 重新生成图标后要覆盖 `icon.ico`，它写出的第一项不是最大尺寸。ICO 里 ≤48px 的项（覆盖 100%–200% 缩放下的任务栏尺寸）由 `src-tauri/icons/source/icon-small.svg`（小尺寸专用稿）渲染，更大的项由 `icon-windows.svg`（满版）渲染；`32x32.png` 同样取小尺寸稿。主稿的细声柱在 36px 下会糊成一片，所以任务栏尺寸不能用主稿缩小。
4. Windows 版底板要铺满画布：任务栏里其他应用的图标都占满 36×36，底板留边距就会显得小一圈。

## 排查方法

- 判断是不是这个问题：截任务栏，把实拍图标和 ICO 各尺寸缩放后的结果逐像素比较，最接近哪个尺寸，窗口用的就是哪个。
- 不必反复重新编译：向运行中的窗口发 `WM_SETICON`，再截任务栏，就能比较不同尺寸的效果。要找 `Tauri Window` 类的窗口，进程的 `MainWindowHandle` 可能指向隐藏的原生悬浮窗。
