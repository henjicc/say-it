# 智能助手快捷键必须在回调内冻结目标窗口

## 触发条件

- 用户在其他应用中选中文字，再按全局快捷键启动选区编辑或语音问答。
- 快捷键回调把工作异步派发后，才查询当前前台窗口。
- macOS 或窗口系统在这段间隙把本应用、悬浮窗或错误窗视为前台窗口。

此时选区读取会错误地面向“说吧！”自身，随后显示“没有选中文本”；错误窗继续获取焦点后，原应用中的选区状态也更难恢复。

## 正确做法

- 在全局快捷键回调返回前同步冻结 `ActivationTarget`，再把它传入异步助手会话。
- 捕获前若焦点已经短暂漂移，重新激活冻结目标并等待窗口稳定，再按目标进程读取选区。
- 捕获结束仍需重新校验当前窗口，用户真正切换目标时必须停止覆盖。
- 启动阶段的无结果错误窗只显示、不主动抢焦点；只有存在可恢复结果时才聚焦回答窗。
- 回归测试和人工验证都应覆盖“主窗口已打开但位于后台”的情况，不能只测托盘驻留状态。
