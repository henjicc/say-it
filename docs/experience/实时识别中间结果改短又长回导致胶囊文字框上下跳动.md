# 实时识别中间结果改短又长回导致胶囊文字框上下跳动

## 现象

录音时胶囊上方的实时文字，在流式更新过程中文字框高度和滚动位置频繁上下跳，文字像是往上蹿一下、消失又出现。

## 原因

实时识别的中间结果经常把末尾改短（甚至少一行），下一次又长回来。显示层逐条照搬几何：

- 文字框高度、宽度、滚动量都按最新一条文本立刻重算，短一行就回落、长回来再顶上去；
- 新字淡入只和上一条文本比前缀，末尾先被改短的字在长回来时被当成新字从透明淡入。

## 做法

- 文字框几何（宽、高、滚动量）变大立即跟上，变小要持续一段时间（当前 600ms）仍未长回来才收拢；量出的尺寸再变化时重新计时。原生胶囊在 `crates/overlay-core/src/indicator.rs`，WebView 文本轨道在 `ui/src/indicator/IndicatorApp.tsx`，两边语义保持一致。
- 淡入的「新字」按本段显示过的最长文本判断（`seen_text` / `seenText`），只有从未显示过的字才淡入。
- 原生字幕滚动模式（`crates/overlay-core/src/subtitle/model.rs` 的 `scroll_offset_y`）目前仍实时跟随内容高度，若出现同样跳动按同一做法处理。
