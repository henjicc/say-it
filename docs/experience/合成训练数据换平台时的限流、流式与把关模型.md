# 合成训练数据换平台时的限流、流式与把关模型

适用：用 `scripts/synth-intent-data.py` 在新平台或新模型上合成数据。

## 先小批量试跑，再全量

换平台或模型时，先用 `SYNTH_OUT=<临时目录> SYNTH_SCALE=0.03` 试跑，看三样东西：

- **保留率**：和原平台同类任务对比（DeepSeek-V4.1-Flash 的参考值：翻译口述约 55%，翻译选中约 75%，查词约 70%）。保留率明显偏高时，往往是质检放水，不是质量更好。
- **速度**：每 20 分钟新增的条数。
- **报错**：429、解析失败、账号状态类错误。

## 限流按「每秒发起数」时必须匀速发

有的平台按每秒发起的请求数限流（例如百灵每秒 2 次），并发一齐发出会被大面积 429，退避重试后整体反而更慢。要设 `SYNTH_QPS` 让请求均匀发出。判断方法：

- 间隔 1 秒逐个发，全部成功；
- 一次并发 10 个，大半失败。

符合这两条，就是按发起数限流。

## 长思考要用流式

部分平台（百灵 Ling）开启思考后，非流式调用会卡住直到超时，所以脚本统一用流式。如果流式也迟迟返回不完（一批输入近 10 分钟没写完），说明这个平台吞吐不够，不适合批量合成，直接换平台。

## 生成模型不能给自己把关

GLM-5.3-Flash 自己质检时，保留率比 DeepSeek 高很多；用 DeepSeek 复检它保留的样本，有 19% 不合格。它做意图复核也不稳定，同一批样本重复复核，结果会来回翻转。所以：

- 生成输入、写答案可以用便宜模型；
- 复核意图和质检都交给可靠模型，用 `SYNTH_JUDGE_MODEL`、`SYNTH_JUDGE_KEY` 设置；
- 已经用弱模型复核过的数据，打包前要用把关模型重新复核一遍，不一致的剔除。

## 免费额度用尽后的账号状态

SCNet 的免费 token 用完后，会转为扣现金余额；余额为 0 时变成欠费，按量 Key 返回 `431 Account Suspension`（报错文字却是 Request Header Fields Too Large）。看到 431 时，先查免费额度和余额，不要当成请求头问题去排查。套餐专属 Key（Token Plan）与按量 Key 是两本账，互不影响。
