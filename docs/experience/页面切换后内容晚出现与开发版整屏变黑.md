# 页面切换后内容晚出现，与开发版整屏变黑

## 现象

- 切到历史、模型 › 用途、设置 › 通用等页面时，有一部分内容晚几十到几百毫秒才出来；历史先显示「暂无记录」再出列表，助手页先显示默认设置再换成真实设置。
- 开发版里切页面偶尔整个窗口变黑，只剩背景色。

## 根因

- 这些组件在挂载时各自 `cmd(...)` 读数据、放进组件自己的 state，每次进页面都从空开始。助手、历史、诊断设置甚至每次都重读整份 `get_app_snapshot`。
- 整屏变黑：界面没有错误边界，任何一次渲染出错 React 都会卸掉整个界面。开发版里改代码热更新时，正在显示的组件 hook 数量变了就会抛 `Should have a queue` / `change in the order of Hooks`，于是黑屏。

## 做法

- 设置类数据从 `store/useAppSettingsStore.ts` 读：启动时写入，保存后用 `update_app_settings` 返回的整份设置刷新。不要在组件里再读快照。
- 命令结果用 `hooks/useCachedQuery.ts`：先显示上次读到的，后台再读；`data` 为空表示还没读到，不要显示空状态。数据刚变过用 `refresh()` 强制重读；写操作拿到新结果用 `setQueryData`。
- 主要页面的数据在 `features/app/prefetchPages.ts` 里启动时预取，新页面要读的数据也加进去。
- 内容区包在 `components/shell/PageErrorBoundary.tsx` 里，出错只换掉当前页面并显示原因。

## 怎么排查

开发版用 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9223` 启动后，可以连 `http://127.0.0.1:9223/json` 拿到页面的 WebSocket，用 CDP 读界面里的异常和调用栈；逐个点导航，记录点击后两帧的文字和之后一段时间里的 DOM 变化，就能量出哪些页面有内容晚出现。
