# DirectWrite 逐行纵向吸附导致滚动文字抖动

## 现象

听写胶囊文字满三行后向上滚动时，文字有细微的上下抖动，滚动结束时仍能看到，靠裁剪边的首行最明显。字幕条滚动模式同理。

## 原因

Windows 原生悬浮窗用 Direct2D `DrawTextLayout` 绘制文字，选项为 `D2D1_DRAW_TEXT_OPTIONS_NONE`。此时 DirectWrite 会把**每一行的基线分别**纵向吸附到物理像素。

胶囊的滚动偏移是弹簧动画的小数值，行高换算成物理像素通常也带小数，于是各行的小数部分不同。滚动时各行在不同帧各自跳 1px，彼此错动，看起来就是抖。弹簧阻尼比约 0.99、裁剪矩形不动，都不是来源。

## 做法

`desktop/native_win/d2d.rs` 的 `D2dCanvas::draw_text` 先用 `align_baseline_to_device` 把文字起点的 y 按当前变换和 dpi 对齐到物理像素：整块文字按整像素一起移动，各行的小数部分固定，静止时也清晰。x 不对齐，横向滚动（字幕替换模式）保持亚像素平滑。

不用 `D2D1_DRAW_TEXT_OPTIONS_NO_SNAP` 的原因：它能让动画平滑，但静止文字会略糊。

Mac 后端 CoreText 不做逐行纵向吸附，不需要同样处理。

## 验证

像素快照 record → 改动 → verify 时，只有含文字的帧出现亚像素差异，属预期；抽看前后图一致后，在主检出重录基准再 verify 全绿。滚动是否还抖只能在真机上看。
