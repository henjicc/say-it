# 十六进制颜色解析按字节切片导致非 ASCII 输入崩溃

用户设置中的颜色不一定是 ASCII。`str.len()` 返回字节数，仅校验三位或六位长度不能保证按字节切片安全：`中` 占三字节，`中abc` 占六字节，固定下标会跨 UTF-8 字符边界并 panic，使默认色回退失效。

主题与字幕共用 `overlay-core::look::parse_hex_rgb`，直接验证并解码 ASCII 十六进制字节；三位色展开为重复半字节，六位色按通道解码。格式前缀、空白和主题仅允许六位色的约束由调用方处理，非法字符返回 `None`。

回归必须同时覆盖主题与字幕入口的中文、全角字符、空串、单独 `#` 和非十六进制 ASCII。合法输入以原算法对照全部三位颜色及各六位颜色通道，确认结果保持一致。
