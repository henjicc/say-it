# 普通识别插件不得强制要求浏览器会话

## 触发条件与根因

文件模型与实时模型混合对比的本地应用验收中，API v5 无认证实时插件启动失败，报“插件没有声明 browserSession”。插件清单合法，运行时不需要网页登录。

`refresh_browser_session_before_runtime` 同时服务实时识别和录音启动，原先把可选的浏览器配置当成必填。没有 `browserSession` 时应直接成功返回；有浏览器配置时仍按 `requires_capture` 判断是否需要续期，保留原来的登录窗口和失败传播。

## 验证边界

隔离应用验收插件不声明浏览器会话、没有网络权限，同时提供文件和实时模型。必须通过实际模型启动命令覆盖此路径；只验证清单加载或文件转写不会经过同一前置检查。普通插件的放行不能变成忽略需要网页登录插件的续期失败。
