# CoreGraphics 翻转裁剪负尺寸与 CoreText 极窄断行

适用：macOS 原生悬浮窗离屏画布与手动文字排版。

## 翻转坐标后的裁剪矩形

CoreGraphics 坐标转换可能保留负矩形尺寸。画布用 `scale(s, -s)` 建立左上原点时，不能把 `convert_rect_to_device_space` 的 origin 当作最小端点，再用 `size.max(0)` 修补；这会把有效裁剪压成空矩形。

正确做法：转换矩形两个端点，在设备空间分别取 min/max，再按像素中心规则取整；回到用户空间后同样从两个端点重建正向矩形。轴翻转还会把 `[min,max)` 变为 `(min,max]`，边界落在像素中心时必须保留包含关系。

回归覆盖：普通缩放、平移、负缩放、恰好位于半像素的边界、save/restore 后恢复裁剪。macos-15 离屏像素测试可直接验证，交叉 `cargo check` 无法发现。

## 极窄文字与硬换行

`CTTypesetterSuggestLineBreak` 在首字形宽于布局时可能返回 0。强制放入一个 Unicode 标量后，需要把紧接的 LF/CR/CRLF 归入该行，否则换行符本身又占一行，导致 `😀\n` 被计为三行。已经以硬换行结束的行不能再吞掉下一个换行，连续空行必须保留。

回归覆盖：极窄宽度下的代理对、LF、CRLF、连续换行、尾部空行，且不改变正常中文 UNIFORM 行高与单行替换模式。

## 绘图测试的串行锁

所有 CG/CT 测试使用 `cg::CG_TEST_LOCK`，避免并发绘图串色。每个测试独占自己的上下文，因此前序断言失败后可以恢复中毒锁的 guard，继续串行执行后续测试；首个失败仍由测试框架报告，避免其余用例只剩 `PoisonError` 而丢失诊断信息。
