# LLM 问答与普通处理的场景默认及输出边界

## 适用场景

智能问答与翻译、编辑、智能优化共用 LLM 配置，但请求参数和输出协议不同，不能只靠页面状态区分。

## 规则

- 智能问答默认使用较高推理强度、请求联网搜索，并走流式输出；正文按 Markdown 渲染，思考片段单独展示。
- 翻译、编辑和智能优化默认关闭推理与联网搜索，提示词要求 JSON 输出，解析兼容代码围栏和前后多余文字；不请求供应商的 JSON 输出模式（SDK 目录里很多模型没声明支持，请求会被拒绝）。
- 联网搜索只传「是否联网」，挂什么工具、哪些供应商与协议不挂由 SDK 决定。
- 思考的开启、关闭与强度只传用户设置的档位，各家字段写法、关不掉时怎么办都由 SDK 决定。

## 维护提示

协议、地址、思考与联网的供应商差异都在 `@henjicc/ai-sdk`，说吧这边发现不对就让 SDK 改，不在 `smart_text.rs` 补供应商分支。
