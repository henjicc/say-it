# CSS hover 与加载动画共用 transform 导致动画冻结

## 现象

悬浮球在录音结束后进入识别或智能处理状态，加载图标停在某个角度，看起来像处理流程卡死。问题常在鼠标点击后仍停留于悬浮球上时出现。

## 根因

加载图标用 `transform: rotate(...)` 实现旋转，而悬浮反馈又在同一个 SVG 元素上用 `transform: scale(...)`。状态切换与 `:hover` 残留会让两套样式竞争同一个 `transform` 属性，WebView 重新计算样式时可能使旋转动画停止或被缩放值覆盖。

## 正确做法

把变换职责分到不同元素：

- 外层容器只负责 hover 缩放和过渡；
- 内层图标只负责持续旋转；
- 波形条等自身已经使用 `transform` 的动画元素，也不要直接承载父级 hover 变换。
- 多个连续处理阶段复用同一种加载图标时，用阶段作为组件 `key`，让阶段切换明确重启动画周期。

连续动画与交互反馈需要组合时，优先增加轻量包装层，不要让同一个 DOM 元素上的多个状态同时写 `transform`。
