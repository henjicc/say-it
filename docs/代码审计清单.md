### [x] 4 ✅ 字幕翻译字节游标跨会话残留 → panic 并锁死整个字幕域 —— **已修复 `304100e`**

- **影响**：① 在最需要剪贴板回退的那批应用（Chromium / Electron / VS Code / PDF）里，明明选中了文本却被告知「请先选中需要修改的文本」；② 用户原有剪贴板被选区文本永久覆盖；③ 每次超时都要重新拉起探针进程。
- **修法**：选区捕获改用完整的 `resolve`（800ms `NATIVE_TEXT_CAPTURE_TIMEOUT` 预算），或新增 `resolve_for_selection`；并让探针在被取消时先有机会恢复剪贴板再退出（reset 前发 abort 帧 + 宽限期），而不是在复制与恢复之间直接 `TerminateProcess`。

### [ ] 49 ✅ AudioSession 对同一 owner 复用 generation，过期 finalize 会释放新会话的租约

- **触发**：开启智能处理 → 听写停止 → finalize 进入 LLM 阶段 → 按 ESC 取消 → 立刻重新开始听写（拿到同 generation 的别名租约）→ 旧 finalize 返回后走 `cleanup_stale_finalize` 释放该 generation。

### [ ] 50 ⚠️ file 模式听写把整段 PCM 无上限累积在内存

- **位置**：`src-tauri/src/application/dictation.rs:1271`

- **量级**：48kHz 单声道每分钟约 11.5MB；按停止键时瞬时峰值约每分钟 23MB → 30 分钟约 690MB，1 小时约 1.4GB。
